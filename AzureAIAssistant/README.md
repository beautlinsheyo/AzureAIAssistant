 AzureAIassistant

An ASP.NET Core project integrating Azure AI for intelligent chat assistance with database persistence.

## 🚀 Features
- Chat assistant powered by Azure AI
- ASP.NET Core + EF Core
- SQLite database with migrations
- Demonstrates dependency injection

## ⚙️ Setup
1. Clone the repo
2. Run `dotnet ef database update`
3. Start the project with `dotnet run`
